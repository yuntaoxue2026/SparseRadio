# Figure attribution

Figures using RadioMapSeer simulated signals or city layouts are derived from data by **Çağkan Yapar, Ron Levie, Gitta Kutyniok and Giuseppe Caire**, available from [RadioMapSeer](https://radiomapseer.github.io/index.html), labelled [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) on the official publisher's page. Cite their [dataset paper](https://arxiv.org/abs/2212.11777).

SparseRadioMap modifications: outdoor masking, sparse sampling, colour mapping to saved pathgain in dB, computed model predictions/errors, statistical aggregation, panel layout and annotation. Predictions and analyses are by Yuntao Xue; no endorsement by the dataset authors is implied. Displayed originals remain truncated/quantized simulated signals, not field measurements or recovered pre-truncation values.

The public candidate contains selected attributed figures, numerical statistics and code. It does not contain the original ZIP, processed arrays, masks or raw prediction arrays. The complete local package separately contains these derived arrays and historical figures. Historical baseline images should be accompanied by this attribution if reused; the old report's missing-license conclusion has been corrected by DATA_LICENSE.md.

Underlying city layouts originate from OpenStreetMap, as described in the dataset paper. Map-layout credit: **© OpenStreetMap contributors**, with upstream database licensing information at https://www.openstreetmap.org/copyright (ODbL). Display figures are adapted raster presentations, not a redistribution of an OSM database; the dataset publisher's CC BY 4.0 notice and upstream map attribution are both retained.
